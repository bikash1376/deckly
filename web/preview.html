Review

Built, not mocked. Every screen here now exists in the app. The deck card is built from stacked Views rather than an SVG path, in both the app and this preview: the shape composes just as well out of rounded rectangles, and Views recycle far more cheaply in a list.

What is not settled. Prices are placeholders. Illustration style for empty states is still open, the reference screens use abstract collage art that we would need to licence or commission.

Copy across the whole app avoids em dashes and emoji. That rule is enforced in code by cleanCopy() in src/lib/copy.ts, which runs over model output before it is stored, because models produce em dashes whatever the prompt says.
